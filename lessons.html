Lesson 1: Logical operators

Covers outcome 2: truth tables for NOT, AND and OR, and for expressions that use up to three operators. You do not need any earlier topic for this lesson.

Step 1

True or false, 1 or 0

  • Computers make decisions using statements that are either true or false. There is nothing in between.
  • We write 1 for true and 0 for false.
  • We give each statement a letter. For example, A = "it is raining". If it is raining, A = 1. If it is dry, A = 0.
Step 2

NOT gives the opposite

  • NOT has one input. It flips it: 1 becomes 0 and 0 becomes 1.
  • If A = "it is raining", then NOT A = "it is not raining".

Step 3

AND needs both

  • AND has two inputs. The answer is 1 only when both inputs are 1.
  • Everyday example: you can log in only if your username is correct AND your password is correct.

Step 4

OR needs at least one

  • OR has two inputs. The answer is 1 when at least one input is 1.
  • Everyday example: the alarm sounds if the door opens OR the window opens.
  • Watch out: if both are 1, the answer is still 1. In everyday speech "tea or coffee" usually means pick one. In logic, OR includes both.

Step 5

Setting out a truth table

  • A truth table lists every possible combination of the inputs and the answer for each one.
  • Each extra input doubles the rows: 1 input has 2 rows, 2 inputs have 4 rows, 3 inputs have 8 rows.
  • To make sure you never miss a row, fill the input columns in this pattern:
    • right-hand column: 0, 1, 0, 1, …
    • middle column: 0, 0, 1, 1, …
    • left-hand column: four 0s, then four 1s
  • The rows are counting in binary, from 000 up to 111.

Step 6

Using more than one operator

  • Work out the brackets first, the same as BIDMAS in maths.
  • Add a working column to your table for each bracket and each NOT.
  • Then combine the working columns to get the final answer, Q.

Worked example: Q = (A AND B) OR (NOT C), when A = 1, B = 0, C = 0.

A AND B = 1 AND 0 = 0

NOT C = NOT 0 = 1

Q = 0 OR 1 = 1

Try it: change the inputs and watch each part

Step 7

Practise building truth tables

The first tables are single operators. Later ones ask you to fill in the working columns as well as Q.

Tap each ? to set 0 or 1

Before you move on

Mistakes to avoid

  • Writing 0 for 1 OR 1. OR is 1 when both inputs are 1.
  • Missing rows. Three inputs always means 8 rows.
  • Applying NOT to the wrong thing. NOT (A AND B) flips the answer to the whole bracket. (NOT A) AND B flips only A.
  • Skipping the working columns. They are where the marks are when something goes wrong.

Lesson 2: Logic gates and adders

Covers outcome 3: logic circuits with NOT, AND, NAND and OR gates, and a simple binary adder. Do Lesson 1 first, because every gate is one of the operators you met there.

Step 1

What a logic gate is

  • A logic gate is a tiny electronic circuit that carries out one logical operator.
  • Wires carry a signal that is either on (1) or off (0).
  • Inputs go in on the left. The output comes out on the right.
  • A processor is built from millions of these gates joined together.
Step 2

The four gate symbols

  • AND: flat back, round front, like a letter D.
  • OR: curved back, pointed front.
  • NOT: a triangle with a small circle.
  • The small circle always means "then flip the answer". So NAND is an AND gate with a circle: work out AND, then flip it.

Try it: tap the switches under each gate

ABA AND BA NAND B
0001
0101

1110
Step 3

Reading a circuit

  • Work from left to right.
  • Write the value (0 or 1) on the wire coming out of each gate before you move to the next gate.
  • The last gate gives the output, Q.

Try it: the blue numbers are the values on the wires

Step 4

Drawing a circuit from an expression

  1. Write the inputs (A, B, C) down the left-hand side.
  2. Draw one gate for each bracket and connect it to its inputs. These gates sit nearest the inputs.
  3. Draw the gate for the operator that joins the brackets. Connect the earlier gates into it.
  4. Label the final output Q.
  5. Check one row: pick values for A, B and C and follow them through.

Example: Q = (A OR B) AND (NOT C)

The brackets give an OR gate (inputs A and B) and a NOT gate (input C). The AND joins them, so it is the last gate.

Practise: choose the gate for each position

Step 5

Truth table for a circuit

  • Add a working column for the wire coming out of each gate.
  • Fill the working columns first, then use them to find Q.

Practise: tap each ? to set 0 or 1

Step 6

Adding in binary

  • Binary only has the digits 0 and 1, so there are only four sums to learn.
  • 1 + 1 is two, which in binary is written 10. You write 0 and carry 1, just like 5 + 5 in ordinary numbers: write 0, carry 1.

Step 7

The half adder

  • A half adder is a circuit that adds two bits, A and B.
  • It needs two outputs: Sum (the digit you write down) and Carry (the digit you carry).
  • Carry is 1 only when both inputs are 1. That is an AND gate.
  • Sum is 1 when the inputs are different. OR tells us "at least one is 1". NAND tells us "not both are 1". Put those two answers into an AND gate and you get "one, but not both".

Try it: add two bits

Step 8

The full adder

  • When you add longer numbers, every column after the first may have a carry coming in. So you need to add three bits: A, B and the carry in.
  • A full adder does this. It is built from two half adders and an OR gate.
  • The first half adder adds A and B. The second adds the carry in to that answer. If either half adder produces a carry, the OR gate passes it on as the carry out.
  • 1 + 1 + 1 is three, which is 11 in binary: Sum 1, Carry 1.

Try it: add three bits

Practise the adder truth tables

Lesson 3: Negative numbers and floating point

Supports outcome 4, criterion 4.4. You need to be comfortable with binary place values (128, 64, 32, 16, 8, 4, 2, 1) before you start.

Step 1

The problem: there is no minus sign

  • A register can only hold 0s and 1s. There is nowhere to write a minus sign.
  • So we need a way to store negative numbers using only bits.
  • The method computers use is called two's complement.
Step 2

The idea: make the left-hand place value negative

  • In ordinary 4-bit binary the place values are 8, 4, 2, 1.
  • In 4-bit two's complement they are −8, 4, 2, 1. Only the left-hand one changes.
  • To read a number, add up the place values where there is a 1, exactly as before.
  • If the left-hand bit is 1, the number is negative. If it is 0, the number is positive or zero.

0101 = 4 + 1 = 5

1011 = −8 + 2 + 1 = −5

1111 = −8 + 4 + 2 + 1 = −1

Try it: tap the bits (4-bit two's complement)

Step 3

How big and how small

  • The same idea works for any number of bits. The left-hand place value is always the negative one.
  • The smallest number is a 1 followed by all 0s. The largest is a 0 followed by all 1s.

Step 4

Writing a negative number: flip the bits and add 1

  2. Flip every bit: each 0 becomes 1 and each 1 becomes 0.
  3. Add 1.

Step 5

Binary fractions

  • Moving left, each binary place value doubles: 1, 2, 4, 8.
  • Moving right past the binary point, each one halves: ½, ¼, ⅛, 1⁄16.
  • As decimals these are 0.5, 0.25, 0.125 and 0.0625.
  • A fixed point number keeps the point in one agreed place. Here we use 4 bits before the point and 4 after.

0101.1100 = 4 + 1 + ½ + ¼ = 5.75

0010.0100 = 2 + ¼ = 2.25

Try it: tap the bits (fixed point)

Practise fixed point

Step 6

Floating point: the same idea as standard form

  • In GCSE maths you met standard form: 3.2 × 10⁴ = 32 000. The power of ten tells you how far to move the decimal point.
  • Floating point does the same thing in binary, using powers of two:

value = mantissa × 2exponent

  • The mantissa holds the digits of the number.
  • The exponent says how many places to move the binary point. Positive moves it right (the number gets bigger). Negative moves it left (the number gets smaller).
  • Multiplying by 2 doubles. Multiplying by ½ halves.
  • This lets a small register hold very large and very small numbers.

Step 7

Reading a floating point register

  • Our 8-bit register is split into a 5-bit mantissa and a 3-bit exponent.
  • Both parts are in two's complement, which is why you needed Steps 1 to 4.
  • Mantissa place values: −1 . ½ ¼ ⅛ 1⁄16 (the binary point comes after the first bit).
  • Exponent place values: −4 2 1.
  1. Work out the mantissa.
  2. Work out the exponent.
  3. Multiply the mantissa by 2 to the power of the exponent.

01010 010

Mantissa 0.1010 = ½ + ⅛ = 0.625

Exponent 010 = 2

0.625 × 4 = 2.5

01100 111

Mantissa 0.1100 = ½ + ¼ = 0.75

Exponent 111 = −4 + 2 + 1 = −1

0.75 × ½ = 0.375

10110 011

Mantissa 1.0110 = −1 + ¼ + ⅛ = −0.625

Exponent 011 = 3

−0.625 × 8 = −5
