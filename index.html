1.1

Carry out set operations on three sets, including complements, unions and intersections, the universal set and the empty set

Recap

  • U is the universal set: everything we are considering. ∅ is the empty set: no elements at all.
  • A ∪ B (union): in A or B or both. A ∩ B (intersection): in both A and B.
  • A′ (complement): in U but not in A. You may also see this written Aᶜ or Ā.
  • Work out brackets first, the same as in arithmetic.
  • Useful facts: A ∩ ∅ = ∅, A ∪ ∅ = A, A ∪ U = U, A ∩ U = A, U′ = ∅, ∅′ = U.
  • Example with U = {1, …, 8}, A = {1, 2, 3, 4}, B = {3, 4, 5}: A ∪ B = {1, 2, 3, 4, 5}, A ∩ B = {3, 4}, (A ∪ B)′ = {6, 7, 8}.

1.2

Draw Venn diagrams for at most three sets and the universal set

Recap

  • Draw a rectangle for U, then three overlapping circles. That gives 8 regions, counting the area outside all the circles.
  • Union: shade everything inside either set. Intersection: shade only the overlap. Complement: shade everything outside the set.
  • If you are unsure, test the regions one at a time: does a point in this region satisfy the expression?

1.3

Solve problems using at most three sets

Recap

  • Sketch the Venn diagram and fill it in from the middle outwards.
  • Start with the number in all three. Each "both" figure includes those people, so subtract the middle to get the "these two only" regions.
  • For each "only" region, subtract the three regions already filled in that circle from the circle's total.
  • None = total surveyed minus everything inside the circles.

2.2

Construct truth tables for NOT, AND and OR

Recap

  • NOT flips the input: 0 becomes 1, 1 becomes 0.
  • AND gives 1 only when both inputs are 1.
  • OR gives 1 when at least one input is 1.
  • A table with n inputs needs 2ⁿ rows. List the rows in binary counting order (00, 01, 10, 11) so none are missed.

2.1

Construct truth tables using up to three operators

Recap

  • Three inputs means 8 rows, 000 to 111.
  • Add a working column for each bracket or NOT, then combine those columns for the final output.
  • Example: for (A AND B) OR C, work out the A AND B column first, then OR it with C.

3.2

Construct logic circuits for at most three inputs, including NOT, AND, NAND and OR

Recap: the four gate symbols

  • The small circle on a symbol means "invert". NAND is AND followed by NOT, so its output is 0 only when both inputs are 1.
  • To build a circuit from an expression, start with the brackets: those gates sit nearest the inputs. The operator joining the brackets is the last gate, which produces the output Q.

3.3

Construct a simple binary adder circuit

Recap

  • A half adder adds two bits, A and B. It has two outputs: Sum and Carry.
  • Carry = A AND B. Sum is 1 when exactly one input is 1.
  • Using only the gates in this unit: Sum = (A OR B) AND (A NAND B). The circuit is drawn below.
  • A full adder adds three bits: A, B and a carry in. It is built from two half adders and an OR gate. Sum is 1 when an odd number of inputs are 1; carry out is 1 when two or more inputs are 1.

4.1

Express numbers in binary and hexadecimal

Recap

  • Binary place values for 8 bits: 128 64 32 16 8 4 2 1. Work left to right: if the place value fits, write 1 and subtract it; if not, write 0.
  • Hexadecimal is base 16. Digits: 0–9 then A=10 B=11 C=12 D=13 E=14 F=15.
  • Denary to hex: divide by 16. The whole-number result is the first digit and the remainder is the second. Example: 174 ÷ 16 = 10 remainder 14, so 174 = AE.

4.2

Convert numbers between binary and hexadecimal formats

Recap

  • One hex digit is exactly four bits (a nibble).
  • Binary to hex: split into groups of four from the right and convert each group. 1011 0110 is 11 and 6, so B6.
  • Hex to binary: write each digit as four bits. 3C is 0011 1100.

4.3

Express numbers and letters in ASCII and Unicode formats

Recap

  • ASCII gives each character a 7-bit code (128 characters), normally stored in an 8-bit byte.
  • Codes to remember: space = 32, '0' = 48, 'A' = 65, 'a' = 97. Digits and letters run in order, so 'C' = 67 and '5' = 53.
  • The character '5' (code 53) is not the same as the number 5.
  • Unicode covers far more characters. Each has a code point written U+ followed by hex, for example € is U+20AC. The first 128 code points match ASCII, so 'A' is U+0041.

4.4

Express register contents as binary, hexadecimal, fixed point or floating point numbers

Recap

  • A register holds a fixed number of bits. The same bits can mean different things depending on how they are read.
  • Fixed point (here: 4 bits before the point, 4 after). Place values: 8 4 2 1 . ½ ¼ ⅛ 1⁄16. So 0101.1100 = 4 + 1 + ½ + ¼ = 5.75.
  • Floating point: value = mantissa × 2exponent. Read the exponent, then move the binary point that many places (right if positive, left if negative).
  • 3-bit two's complement exponents: 000=0 001=1 010=2 011=3 100=−4 101=−3 110=−2 111=−1.

Floating point questions here use an 8-bit register: a 5-bit mantissa with the binary point after the first bit, then a 3-bit exponent, both in two's complement. Check this matches the layout used in your class notes.
